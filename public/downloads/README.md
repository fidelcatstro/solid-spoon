## Drop the prebuilt Android APK here

Place the signed-for-sideload APK at:

    public/downloads/app-release.apk

The `/api/download-apk` route automatically picks it up and serves it
with the right `application/vnd.android.package-archive` mime type and
filename (`s2000-gauges-vX.Y.apk`), so users can just click the
download link in the app.

The companion `/api/download-apk/status` route reports whether a file
is present, its size, and the version label — the in-app download
button polls this so it can show "preparing" until you drop a real
APK in.

To produce or refresh the file, see
[`android/README.md` → "Refreshing the bundled APK"](../../android/README.md#refreshing-the-bundled-apk).

This directory is intentionally tracked in git so the APK can ship with
the repo. The APK itself is not generated by the dev workflow — it
must be built on a machine with the Android SDK and copied in.
